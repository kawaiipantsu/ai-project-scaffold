# Project Progress

This file tracks the current progress and state of the project.

AI agents should **keep this file updated as work progresses** so developers, users, and future agents can quickly understand what has been completed, what remains, and what is planned next.

## What to Track

Keep a concise record of:

* Completed work
* Current/in-progress work
* Remaining tasks
* Phases or waves for larger projects
* Planned features
* Known issues or fixes needed
* Important follow-up work

For small projects, a simple checklist is sufficient.

For larger projects, organize progress into phases or waves.

```text
## Current Status

Brief description of the current project state.

## Completed

- [x] Completed task
- [x] Completed feature

## In Progress

- [ ] Current task

## Next

- [ ] Planned feature
- [ ] Required fix
- [ ] Follow-up work
```

Update this file as meaningful work is completed or new requirements are introduced.

Remove or reorganize outdated planning information when appropriate, but preserve enough context to understand the project's progression.

The goal is to make `PROJECT_PROGRESS.md` the quickest place to determine:

**What is done? What is being worked on? What is missing? What comes next?**

# Prompt History

This file keeps a record of prompts and important AI interactions used throughout the development of this project.

The purpose is to maintain a simple history that can be reviewed later to understand how AI-assisted decisions, implementations, and corrections were made.

## What to Record

Record relevant AI interactions, including:

* Initial prompts
* Development prompts
* Feature requests
* Correction prompts
* Steering prompts
* Follow-up instructions
* Important AI answers
* Architectural or technical decisions influenced by prompts

Minor or repetitive interactions do not need to be recorded unless they provide useful context.

## Format

Append new entries chronologically:

```text
## YYYY-MM-DD — Short Description

### User
<prompt>

### AI
<relevant answer or summary>
```

Do not rewrite or remove previous entries unless explicitly requested.

## Sensitive Information

Never record passwords, credentials, API keys, tokens, private keys, secrets, or other sensitive information in this file.

Redact sensitive information before recording prompts or responses.

## AI Agents

AI agents should update this file with relevant prompts and responses when working on the project, unless the user explicitly requests otherwise.

Keep the history concise but complete enough to understand important instructions, corrections, and decisions later.
